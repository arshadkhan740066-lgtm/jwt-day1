# 🔐 JWT Authentication API

A beginner-friendly authentication project built with **FastAPI, Python, SQLAlchemy, PostgreSQL, and JWT**.

This project is created to understand how user authentication works in a REST API and how authentication can be connected with a database.

## 🚀 Skills Demonstrated

- Python
- FastAPI
- REST API Development
- PostgreSQL
- SQLAlchemy ORM
- Database Connection
- CRUD Operations
- Pydantic
- Data Validation
- JWT Authentication
- Password Handling
- Dependency Injection
- API Testing with Postman
- Git & GitHub
